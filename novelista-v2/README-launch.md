Needs Python 3.11+ (python.org). Nothing else.
Windows: double-click `start.bat` (first run installs, ~1 min); `stop.bat` to quit (`stop.bat --full` also stops Ollama).
macOS: double-click `start.command`; `stop.command` to quit. If macOS refuses: `chmod +x start.command stop.command`.
The app opens at http://127.0.0.1:8000 (or 8001-8010 if busy). Log: `.run/server.log`.
LM Studio / Ollama are not started by the launcher; start them yourself.
